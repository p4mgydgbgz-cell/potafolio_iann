# Portafolio Digital de Iann

Portafolio web personal con tres pestañas:

- **Quién Soy** — presentación, foto de perfil y línea de tiempo de mi trayectoria.
- **Proyectos 2026** — seguimiento mensual de proyectos y barra de progreso del año.
- **Objetivos a 5 Años** — plan de acción año a año (marketing digital, ventas, trading, dropshipping e inversión).

## Tecnologías

- HTML5 y CSS3 puros (sin frameworks)
- JavaScript vanilla para pestañas, modo claro/oscuro y animaciones al hacer scroll
- Bootstrap Icons (CDN) y Google Fonts (Poppins)

## Estructura

```
portafolio-digital-de-iann.html   # estructura de la página
estilos.css                        # estilos, temas claro/oscuro y responsive
script.js                          # pestañas, tema y scroll reveal
perfil-iann.jpg                    # foto de perfil (optimizada, 600x600)
Sin título.jpeg                    # foto original sin procesar
```

## Uso

Abre `portafolio-digital-de-iann.html` directamente en el navegador, no requiere servidor ni instalación.
